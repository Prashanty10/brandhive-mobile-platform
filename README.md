# BrandHive

**BrandHive** is a full-stack advertising marketplace built to connect **advertisers** with **ad-space owners** for both online and offline advertising opportunities.

The platform allows users to discover advertising options such as **hoardings, malls, buses, auto-rickshaws, social media, and digital platforms** from one application.

## ✨ Features

* 🔐 User Registration & Login
* 🔑 JWT Authentication with Access & Refresh Tokens
* 👤 User Profile Setup
* 📍 Location-Based Ad Discovery
* 🏙️ Offline Advertising Categories
* 🌐 Online Advertising Categories
* 🔎 Discover Advertising Opportunities
* 📅 Booking Management
* 🔒 Secure Token Storage

## 🛠️ Tech Stack

**Frontend**

* React Native
* Expo & Expo Router
* Axios

**Backend**

* Node.js
* Express.js
* MongoDB
* JWT & bcrypt

**Services & Tools**

* Cloudinary
* Postman
* Git & GitHub
* Figma

## 🚀 Run Locally

```bash
# Clone repository
git clone <your-repository-url>

# Install dependencies
npm install

# Start Expo
npx expo start
```
